# 🧬 LIG DNA TODO APP (스마트 워크 & 업무 플래너)

**LIG DNA TODO APP**은 디지털 전환(DX) 및 RPA 스마트 워크 환경에 최적화된 고성능 파이썬 Flask 기반 할 일 및 업무 관리 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **프리미엄 글래스모피즘 & 모던 디자인**
   - 다크 모드(기본) 및 라이트 모드 실시간 원클릭 전환
   - LIG DNA 브랜드 테크 블루 & 사이언 글래스 테마
   - 한글 전용 Pretendard 웹폰트와 유려한 반응형 레이아웃

2. **직관적인 스마트 할 일 관리 (CRUD)**
   - 업무 / DNA혁신 / 프로젝트 / 개인 / 학습 카테고리 태깅
   - 긴급 / 높음 / 보통 / 낮음 우선순위 배지 (긴급 작업 펄스 애니메이션)
   - 마감일자 선택 및 실시간 D-Day / 초과일자 계산
   - 중요 업무(★) 상단 고정 및 인라인 편집/삭제/완료 토글

3. **실시간 통계 및 대시보드**
   - 전체 업무 달성률 프로그레스 바 & 진행 중/오늘 마감/중요/완료 통계
   - 탭 필터링 (전체, 진행 중, 중요, 오늘 마감, 완료됨)
   - 카테고리별 필터 및 우선순위/마감일/최신순 정렬 지원
   - 실시간 키워드 검색

4. **LIG DNA 특별 업무 지원 기능**
   - **원클릭 업무 프리셋**: LIG 핵심 업무(RPA 점검, DX 혁신 과제 등) 즉시 입력
   - **DNA 포커스 모드 (뽀모도로 타이머)**: 25분 집중 / 5분 휴식 타이머 내장
   - **데이터 백업 (Export)**: JSON 형식으로 안전한 데이터 내보내기 지원
   - **완료 업무 일괄 정리**: 원클릭으로 완료된 할 일 아카이빙 및 청소

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 더블 클릭으로 간편 실행 (가장 쉬운 방법)
- 폴더 내 **`run.bat`** 파일을 더블 클릭하면 자동으로 브라우저가 열리며 앱이 실행됩니다.

### 방법 2. 터미널(명령 프롬프트 / PowerShell)에서 실행
```bash
# 1. 앱 폴더로 이동
cd LIG_DNA_TODO_APP

# 2. 패키지 설치
python -m pip install -r requirements.txt

# 3. 앱 실행
python app.py
```
실행 후 웹 브라우저에서 **`http://127.0.0.1:5000`** 으로 접속합니다.
